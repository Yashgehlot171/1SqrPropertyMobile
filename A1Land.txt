# A1Lnad Mobile App - Complete React Native Development Prompt

Project Name:
A1Lnad

Project Type:
React Native Mobile Application

Platform:
Android + iOS

Development Mode:
Frontend UI/UX and complete static workflow first.
Do not integrate real APIs now.
Use static mock data/local state for now.
After complete design and frontend workflow is completed, APIs will be integrated later.

Main Objective:
Create a complete production-ready React Native mobile app for UrbanKart using static data. The app should include full workflow for Buyer, Seller, Broker, Property Search, Add/Edit/Delete/View Property, Saved Properties, Portfolio, Lead Management, Construction Services, House Development Quotation Calculator, Loan Calculator, Legal Department, Property Verification, Property Registration, Support System, Notifications, Profile, Status Update, Remarks, and Document Upload UI.

Important Instruction:
Build the complete mobile app UI and workflow using static data only.
All Add, Edit, Delete, View, Status Update, Remark, Upload, Save, Filter, Search actions should work locally using state management.
Create API-ready service files so real APIs can be integrated later.
Do not skip any module.
Do not hardcode repeated UI. Use reusable components.
Keep code clean, scalable, and production-ready.

Tech Stack:
- React Native
- TypeScript
- React Navigation
- Stack Navigation
- Bottom Tab Navigation
- Redux Toolkit or Zustand for local state management
- React Hook Form
- Yup or Zod validation
- Axios setup for future API integration
- AsyncStorage for login/session/user role/profile storage
- Vector icons
- Safe Area View
- Keyboard Avoiding View
- Reusable components
- Static mock data
- API-ready folder structure

Important Local Functionality:

Since APIs are not integrated:
- All Add/Edit/Delete/View must work using local state.
- Use mock data as initial data.
- When user adds a new property/request/ticket, add it in local state.
- When user edits, update local state.
- When user deletes, remove from local state after confirmation.
- When user updates status, update local state.
- When user adds remark, append to remark list.
- Do not reset data until app reload unless using AsyncStorage.
- Use AsyncStorage for login role/profile if possible.
